# Sponsorship assets

The Alipay payment QR code is stored here as `alipay.png` (542x572 PNG).

- Recommended size: 600x600 or larger, PNG.
- The QR code is public once committed. Mask your real name, phone number, or other personal details if the payment page shows them.
- For overseas sponsors, prefer Ko-fi, PayPal, or Buy Me a Coffee. Alipay personal QR codes are not reliably payable with foreign cards.

The README references `assets/alipay.png`; if you use a different filename, update the README.
